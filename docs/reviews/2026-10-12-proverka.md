## Не исправлено, известно

- **Ввод теряется при ошибке сохранения.** Админка работает формами без
  JavaScript: после сообщения об ошибке форма открывается заново с данными из
  файла. Для коротких правок терпимо; для длинной новости стоит копировать текст
  перед сохранением. Исправление — перевести формы на `useActionState`.
- **Сохранение двух языков — два коммита.** Если второй не пройдёт, первый язык
  уже сохранён. Сверка sha до записи убрала главный повод для этого (чужую
  правку), остаётся только сбой сети между двумя запросами.
- **Загруженные файлы не удаляются.** Убранный документ пропадает со страницы,
  но файл остаётся в `public/uploads/` и доступен по прямой ссылке.
- **Документы без файлов.** Все девять документов и три отчёта по коррупции
  ссылаются на `#` — заказчица их ещё не прислала. `check:content` выводит их
  предупреждениями.
